## Documents and files

### `new_part`

```
new_part(name: str | None = None)
```

Create a new, empty part document (like File > New > Part) and make it active.

### `open_part`

```
open_part(path: str, history: bool = True)
```

Open a document. .oswprt/.oswasm open natively; .step/.stp/.brep and Parasolid .x_t/.x_b are imported as a base feature. .sldprt: with history (default) the feature tree is rebuilt as editable openswx features when every feature is understood and the result matches the file's embedded Parasolid body; otherwise that body is imported as one feature. .sldasm: components (each part read natively) at their saved positions, with the common mates. Everything is read natively: openswx never uses SOLIDWORKS, installed or not.

### `save_part`

```
save_part(path: str | None = None)
```

Save the active document (part .oswprt or assembly .oswasm), optionally to a new path (Save As).

### `save_drawing_document`

```
save_drawing_document(path: str | None = None)
```

Save the drawing as its own document (.oswdrw, like a SOLIDWORKS .slddrw) that refers to its part / assembly file by a relative path (save the model first); opening it opens the model with this drawing.

### `list_documents` *(read-only)*

```
list_documents()
```

List open documents and which one is active.

### `activate_document`

```
activate_document(name: str)
```

Switch the active document.

### `close_document`

```
close_document(name: str | None = None)
```

Close a document (default: the active one). Unsaved changes are discarded.

### `import_file`

```
import_file(path: str)
```

Import a STEP (.step/.stp), IGES, BREP, Parasolid (.x_t/.x_b), SOLIDWORKS part (.sldprt, read natively) or a closed triangle mesh (.stl, .3mf: becomes a faceted solid) into the active part as an Imported feature.

### `export_file` *(read-only)*

```
export_file(path: str, format: Literal['step', 'stl', 'brep', 'x_t', 'iges', '3mf', 'gltf', 'glb'] | None = None)
```

Export the active part's (or assembly's) bodies to STEP, IGES (solids), STL, 3MF (3D printing), glTF / GLB (web / visualisation), BREP or Parasolid text .x_t (opens in SOLIDWORKS and other Parasolid-based CAD); the format is inferred from the extension.

### `export_bom` *(read-only)*

```
export_bom(path: str)
```

Export the active assembly's bill of materials as CSV (item, part number, description, quantity).

### `save_custom_material`

```
save_custom_material(name: str, properties: dict)
```

Save a material to the user's Custom Materials library (kept across documents): density (kg/m^3) is required; elastic_modulus, poisson, yield_strength, tensile_strength, thermal_conductivity, specific_heat, color optional.

### `delete_custom_material`

```
delete_custom_material(name: str)
```

Remove a material from the Custom Materials library.

### `pack_and_go` *(read-only)*

```
pack_and_go(folder: str, prefix: str = '', suffix: str = '', zip_file: str | None = None)
```

Pack and Go: save the active document and every open document it uses (an assembly's parts) into a folder, renamed with a prefix / suffix; zip_file also packs the folder into a .zip.

### `list_recovered` *(read-only)*

```
list_recovered()
```

Document Recovery: documents with unsaved changes left by an openswx session that crashed or was killed (autosaved copies). Each has an id for recover_document / discard_recovered.

### `recover_document`

```
recover_document(id: str)
```

Open a recovered document (id from list_recovered). It opens with unsaved changes under its old name and file path, so Save writes it back to where it belongs; the autosaved copy is then removed.

### `discard_recovered`

```
discard_recovered(id: str | None = None)
```

Delete a recovered document's autosaved copy (id from list_recovered), or all of them when no id is given.

### `save_diagnostic_report` *(read-only)*

```
save_diagnostic_report(path: str, include_documents: bool = False)
```

Help > Save Diagnostic Report: a .zip with the application log (commands, timings, error tracebacks), the program and library versions and the recent command history - what a bug report needs. The open documents are added only with include_documents=True (they are your design data).

### `agent_connection_info` *(UI only, read-only)*

```
agent_connection_info(port: int = 8765)
```

Help > Agent (MCP) Setup: how agents connect to this installation. `stdio` is the command a chat app such as Claude Desktop starts (with openswx open it relays to the open window, so the edits show live there); `http` is the endpoint for clients that can reach this computer (Claude Code); `claude_desktop_config` is where Claude Desktop keeps its MCP servers on this system.


## Queries

### `get_model` *(read-only)*

```
get_model()
```

Summary of the active document. Parts: FeatureManager tree (with status/errors), rollback, bodies, volume, configurations. Assemblies (kind='assembly'): components with positions/DOF and mates.

### `get_feature` *(read-only)*

```
get_feature(name: str)
```

Full definition of one feature (parameters, rebuild state; sketches include geometry, relations, dimensions and solve status).

### `get_topology` *(read-only)*

```
get_topology()
```

List current faces and edges with ids (Face0.., Edge0..), type, a point on each, normals, areas/lengths and radii. Use the ids for fillet, chamfer, shell, hole, sketch-on-face, etc. Ids are only valid until the next model change; `name`, where present, stays valid across edits (a face is named after the feature and sketch entity that made it, an edge 'faceA|faceB' after the two faces it lies between) and is accepted wherever an id is. In assemblies ids are 'Component/Face#'.

### `get_mass_properties` *(read-only)*

```
get_mass_properties()
```

Mass properties of the active part or assembly (mm, g): volume, surface area, mass, centre of mass, inertia tensor at the centre of mass, bounding box and topology counts.

### `list_end_conditions` *(read-only)*

```
list_end_conditions()
```

End conditions accepted by extrude/cut/hole, with their SOLIDWORKS swEndConditions_e values.

### `get_mesh` *(UI only, read-only)*

```
get_mesh()
```

The active document's display mesh for the viewport: triangles per face (with face ids), edge polylines, sketch, plane and reference-geometry overlays.

### `get_activity` *(read-only)*

```
get_activity(limit: int = 30)
```

Recent command log (from the UI and from agents).

### `measure` *(read-only)*

```
measure(a: str, b: str)
```

Minimum distance between two selections (Face#/Edge# ids).

### `face_features` *(read-only)*

```
face_features()
```

Which feature made each face of the part: {"Face3": "Boss-Extrude1", ...} (assemblies: empty).

### `measure_items` *(read-only)*

```
measure_items(items: list[str | Vec3])
```

Measure, as SOLIDWORKS' Measure tool: one item gives its size (face area, radius/diameter, edge length, vertex XYZ); two give the minimum distance, the centre distance of circles/cylinders, dX/dY/dZ and the angle between planar faces or straight edges. Items: Face#/Edge# ids (Component/Face# in an assembly) or [x, y, z] vertices.

### `list_materials` *(read-only)*

```
list_materials(category: str | None = None)
```

The material library: density (kg/m^3), elastic modulus/yield/tensile strength (MPa), Poisson ratio, thermal conductivity (W/m K) and default colour, grouped by category.

### `parent_child` *(read-only)*

```
parent_child(name: str)
```

Parent/Child relationships of a feature: the features it references (parents) and the features that reference it (children), as in the SOLIDWORKS Parent/Child dialog.

### `get_view_image` *(read-only)*

```
get_view_image(view: Literal['isometric', 'front', 'back', 'top', 'bottom', 'left', 'right', 'trimetric'] = 'isometric', width: int = 800, height: int = 600, show_edges: bool = True)
```

Render the active part to a PNG (base64) from a standard view, for visual checks.

### `get_dimension_tolerances` *(read-only)*

```
get_dimension_tolerances(all_dimensions: bool = False)
```

The model dimensions that carry a tolerance, each with its value, deviations, limits and display text (all_dimensions=True also lists the untoleranced ones). A tolerance whose dimension no longer exists is reported under `orphaned`.

### `fit_calculator` *(read-only)*

```
fit_calculator(size: float, hole: str = 'H7', shaft: str = 'g6')
```

ISO 286 fit of a hole and a shaft at a nominal size (mm): both parts' deviations and limits, the minimum and maximum clearance (negative = interference) and the kind of fit (clearance / transition / interference). Classes: holes D E F G H JS K M N P, shafts d e f g h js k m n p, grades 5-12, up to 500 mm.


## Edit and history

### `undo`

```
undo()
```

Undo the last change to the active document. In a cloud document (live collaboration) this takes back your own last change only, and is refused when someone has changed the same thing since.

### `redo`

```
redo()
```

Redo the last undone change.

### `rebuild`

```
rebuild()
```

Force a full rebuild (Ctrl+Q).

### `edit_feature`

```
edit_feature(name: str, params: dict)
```

Change parameters of an existing feature (merged into its current parameters), e.g. edit_feature('Boss-Extrude1', {'depth': 25}). The model rebuilds; invalid edits are rejected.

### `redefine_feature` *(UI only)*

```
redefine_feature(name: str, command_name: str, args: dict)
```

Re-define a feature using the creation command's arguments (used by the UI's Edit Feature). The command runs on a scratch copy to translate selections into parameters.

### `delete_feature`

```
delete_feature(name: str, delete_absorbed_sketch: bool = True)
```

Delete a feature (and its absorbed sketch, as SOLIDWORKS offers).

### `reorder_feature`

```
reorder_feature(name: str, after: str | None = None)
```

Move a feature (with the sketches it consumes) in the FeatureManager to just after `after` (None: the top). Refused when the feature would come before something it references, or vice versa.

### `add_folder`

```
add_folder(name: str, features: list[str])
```

FeatureManager Add to New Folder: group the given features under a folder (display only).

### `remove_folder`

```
remove_folder(name: str)
```

Dissolve a FeatureManager folder; its features stay in the tree.

### `rename_feature`

```
rename_feature(name: str, new_name: str)
```

Rename a feature; references from other features are updated.

### `suppress_feature`

```
suppress_feature(name: str, suppressed: bool = True, configuration: str | None = None)
```

Suppress (or unsuppress) a feature in a configuration (default: the active one).

### `rollback`

```
rollback(to_feature: str | None = None)
```

Move the rollback bar to just below `to_feature`; omit to roll forward to the end.

### `set_material`

```
set_material(name: str, density_kg_m3: float | None = None, properties: dict | None = None)
```

Assign a material. Library names (see list_materials, e.g. 'AISI 1020', '6061-T6 (SS)', 'ABS') bring their density, elastic modulus, Poisson ratio, strengths and colour; any other name needs a density. properties overrides any of: elastic_modulus, poisson, yield_strength, tensile_strength (MPa), thermal_conductivity, specific_heat, color.

### `set_appearance`

```
set_appearance(color: str | None, target: Literal['part', 'feature', 'face'] = 'part', feature: str | None = None, face: str | None = None)
```

Appearance: colour ('#rrggbb', or null to clear) the whole part, a feature's faces (`feature`) or one face (`face` 'FaceN'). Face colours beat feature colours, which beat the part colour.

### `set_custom_property`

```
set_custom_property(name: str, value: str | None)
```

File > Properties: set a custom property (e.g. 'Description', 'PartNo', 'Author'); value null deletes it. Drawings use Description/PartNo/Author in the title block and BOM.

### `set_units`

```
set_units(units: Literal['mm', 'cm', 'm', 'in', 'ft'])
```

Document units (display in the UI and drawings). The API always takes and returns millimetres.

### `batch`

```
batch(commands: list[dict], atomic: bool = True)
```

Run several commands in one call: `commands` is a list of {"name": ..., "args": {...}}. With atomic (default) the first failure puts every open document back as it was before the batch and reports which command failed; on success the whole batch is one Undo step. Returns each command's result in order. Much faster for an agent than one round trip per sketch entity.

### `set_dimension_tolerance`

```
set_dimension_tolerance(dimension: str, type: Literal['none', 'symmetric', 'bilateral', 'limit', 'fit'] = 'symmetric', plus: float = 0.0, minus: float = 0.0, fit: str | None = None)
```

Tolerance on a model dimension ('D1@Sketch1', 'D1@Boss-Extrude1'; names from get_equations). symmetric: +/- plus. bilateral: +plus / -minus. limit: shown as the two limits. fit: an ISO 286 class such as 'H7' (hole) or 'g6' (shaft), its deviations taken from the dimension's size. none: remove it. The tolerance is saved with the part, shown on the dimension in drawings (Model Items) and listed by get_dimension_tolerances with the resulting limits. Values in mm (degrees on an angle).

### `add_requirement`

```
add_requirement(name: str, quantity: Literal['mass', 'volume', 'surface_area', 'size_x', 'size_y', 'size_z', 'longest_side', 'min_thickness', 'dimension', 'bodies', 'errors', 'components', 'interferences'], op: Literal['<', '<=', '>', '>=', '==', '!='], value: float, target: str | None = None, tolerance: float = 1e-06)
```

A requirement the design must keep meeting, saved with the document and checked by check_requirements (and `openswx check FILE` on the command line, for CI). Examples: ('Light enough', 'mass', '<', 250) - mass in grams; ('Fits the bay', 'longest_side', '<=', 200); ('Wall', 'min_thickness', '>=', 1.5); ('Shaft size', 'dimension', '==', 12, target='D1@Sketch1'); ('Rebuilds', 'errors', '==', 0); assemblies: ('No clashes', 'interferences', '==', 0). Lengths mm, volume mm3, area mm2. An existing requirement of the same name is replaced. tolerance: how close counts for == and !=.

### `delete_requirement`

```
delete_requirement(name: str)
```

Remove a requirement by name.

### `sketch_dimension`


### `sketch_spline`

```
sketch_spline(sketch: str, points: list[Vec2 | str], closed: bool = False, construction: bool = False)
```

Add an interpolating spline through `points` ([x, y] or point ids); closed=True makes it periodic.

### `sketch_equation_curve`

```
sketch_equation_curve(sketch: str, x: str, y: str, t_start: float = 0.0, t_end: float = 1.0, points: int = 25, closed: bool = False, construction: bool = False)
```

Equation Driven Curve (parametric): a spline through `points` samples of x(t), y(t) for t from t_start to t_end. The expressions use `t`, the part's global variables, + - * / ^ and the equation functions (sin, cos, tan take degrees, like every openswx equation; sqr, abs, min, max; pi). Examples: an involute x='10*(cos(t)+t*pi/180*sin(t))', y='10*(sin(t)-t*pi/180*cos(t))'; a parabola x='t', y='t^2/20' (the explicit form y = f(x) is x='t'). closed=True joins the end to the start.

### `sketch_text`

Sketch Text: letter outlines at `position` (baseline start), cap height `height` mm, rotated `angle` degrees. The closed letter contours extrude/cut like any profile (counters become holes).

Linear Sketch Pattern: `count` instances `spacing` apart along `angle` degrees (sketch X = 0), with an optional second direction (`spacing2`, `count2`, `angle2`).

Tangent Arc: from `start` (a point id at the end of a line or arc) to `end`, leaving tangent to that line / arc (a tangent relation is added).

Move / Copy / Rotate / Scale Entities: scale by `scale` and turn by `rotate` degrees about `center` ([x, y] or a point id; default the origin), then shift by `move` [dx, dy]. copy=True keeps the originals and returns the new entities.

### `sketch_split`

## Collab

### `collab_sign_in` *(read-only)*

```
collab_sign_in(server: str, email: str | None = None, password: str | None = None, provider: Literal['google', 'github'] | None = None, invite: str | None = None)
```

Sign in to an openswx-collab server for live collaboration (shared cloud documents). Give the server's address (e.g. https://collab.example.com) and either email + password, or provider 'google' / 'github' to sign in through the system browser (the command waits up to 5 minutes for the browser to come back; invite: an invitation token, for a first sign-in on a server that needs one). The server and a session token are kept in the openswx home folder, so this is needed once per machine. Returns {server, user}.

### `collab_server_info` *(read-only)*

```
collab_server_info(server: str)
```

What a collaboration server offers before anyone signs in, as a sign-in dialog needs it: its name and version, the protocol it speaks, how accounts are made (registration: e.g. 'open' or 'invite') and the browser sign-in providers it has set up (oauth: e.g. ['google', 'github']; empty: email and password only). server: its address, e.g. https://collab.example.com. Returns that, with the address as used (server).

### `collab_sign_in_methods` *(read-only)*

```
collab_sign_in_methods()
```

The ways into the signed-in collaboration account: which of Google and GitHub are linked (providers) and whether it has a password (has_password).

### `collab_link_provider` *(read-only)*

```
collab_link_provider(provider: Literal['google', 'github'], password: str | None = None)
```

Add Google or GitHub sign-in to the signed-in collaboration account, through the system browser (the command waits up to 5 minutes for it). password: the account's password (needed if it has one; an account without one needs a sign-in from the last ten minutes instead). Afterwards that provider signs in to this account. Returns {linked, user}.

### `collab_unlink_provider` *(read-only)*

```
collab_unlink_provider(provider: Literal['google', 'github'], password: str | None = None)
```

Stop Google or GitHub signing in to the collaboration account. password: the account's password if it has one. The last way into an account cannot be removed. Returns the remaining sign-in methods.

### `collab_sign_out` *(read-only)*

```
collab_sign_out()
```

Sign out of the collaboration server: every cloud document stops syncing (each stays open as a local copy) and the saved session token is deleted.

### `collab_status` *(read-only)*

```
collab_status()
```

Live collaboration status: the server and who is signed in, and for every open cloud document its connection state, sequence number (seq), role, the other people in it (peers, with their presence and drafts), locks (who is editing which feature), features broken by someone's change (broken: feature id -> {error, by_name, command}), refused changes (conflicts: who changed what first), recent changes from others, and how many of your changes are still waiting for the server (pending).

### `collab_projects` *(read-only)*

```
collab_projects()
```

The organisations and projects you can use on the collaboration server: [{id, name, role, projects: [{id, name, role}]}]. A project is where collab_enable puts a shared document.

### `collab_create_project` *(read-only)*

```
collab_create_project(name: str, org: str | None = None)
```

Create a project on the collaboration server (you become its owner). org: organisation id or name; default: your only organisation. Returns the project {id, name, org_id, role}.

### `collab_documents` *(read-only)*

```
collab_documents(project: str)
```

The cloud documents in a project (project id or name): [{id, name, kind, seq, updated_at, ...}]. Open one with collab_open(id).

### `collab_enable`

```
collab_enable(project: str, name: str | None = None)
```

Turn live collaboration on for the active part: it becomes a cloud document in the given project (id or name; see collab_projects), which others open with collab_open and edit at the same time. From then on every change is sent to the server as you make it; changes from others appear in the model as they come. New features need the connection (their ids come from the server), undo takes back only your own changes, and a change that clashes with someone else's is refused and rolled back with the reason. name: the cloud document's name (default: the part's). Parts only for now. Returns the document id and status.

### `collab_open`

```
collab_open(document_id: str)
```

Open a cloud document (live collaboration) by its id (collab_documents lists them): it opens as a new part showing the server's current state, and stays in sync with everyone editing it. If it is already open it is made active. Returns its status (role, read_only and why, peers).

### `collab_disable`

```
collab_disable()
```

Stop live collaboration for the active document: it stops syncing and stays open as an ordinary local part (save it with save_part to keep it). The cloud document itself stays on the server for the others. Changes still waiting for the server are not sent (pending_dropped says how many).

### `collab_lock` *(read-only)*

```
collab_lock(features: list[str], document: str | None = None, owner: str | None = None)
```

Lock features or sketches of the active cloud document (by name) so nobody else can change them while you work on them, as opening a sketch or a feature's panel does. 'structure' locks the feature tree's shape (deleting and reordering). Locks last while you are connected (and 60 s after a dropped connection); free them with collab_unlock. document: a cloud document id instead of the active one. owner: who in this app took them (the UI passes its page's id, so the locks are freed when that page goes away). Returns {granted: [names], denied: {name: who holds it}}.

### `collab_unlock` *(read-only)*

```
collab_unlock(features: list[str], document: str | None = None, owner: str | None = None)
```

Release locks taken with collab_lock (feature or sketch names, or 'structure'). document: a cloud document id instead of the active one; owner: as given to collab_lock.

### `collab_history` *(read-only)*

```
collab_history(limit: int = 50)
```

The edit history of the active cloud document, newest first: [{seq, author: {name}, time, command, reverts, reverted_by, broke}], plus its named versions. Use a seq or version name with collab_restore.

### `collab_name_version` *(read-only)*

```
collab_name_version(name: str, note: str = '', seq: int | None = None)
```

Name the current state of the active cloud document (or the state after change `seq`) as a version, e.g. 'Rev A'. Named versions are what assemblies pin and what collab_restore can go back to.

### `collab_restore`

```
collab_restore(seq: int | None = None, version: str | None = None)
```

Put the active cloud document back to an earlier state, for everyone: the state after change `seq`, or a named version. Nothing is lost: the restore is itself a new change in the history (and can be restored away). Refused while someone else holds a lock (your own locks do not stand in the way).

### `collab_presence` *(read-only)*

```
collab_presence(pointer: dict | None = None, selection: list[str] | None = None, tool: str | None = None, camera: dict | None = None, draft: dict | None = None, clear_draft: bool = False)
```

Tell the others in the active cloud document where you are: pointer ({point: [x, y, z], face: persistent face name}), selection (persistent names), tool (the command or panel in use), camera (for follow-my-view); draft: unfinished work to preview on their screens (sketch entities, panel parameters), clear_draft to remove it. Relayed as given, never stored. Returns {sent}.
