# Demo assembly

Builds a bracket, a pin and an assembly that uses both:

```bash
python examples/demo/build_demo.py
```

The files go to `examples/demo/out/` and are ignored by git. Open `demo-assembly.oswasm` in openswx to view it. The bracket is a 120 x 80 mm plate with a 44 mm boss, four mounting holes and a 21 mm through hole. The pin is brass and sits in the centre hole.
